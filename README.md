# Starsh Infotech — 3D React Website

Premium dark, monochrome React/Vite website concept inspired by the supplied Starsh particle-spiral logo and the requested high-end agency aesthetic.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The 3D hero uses React Three Fiber + Three.js and generates the particle spiral procedurally, so no external image asset is required for the main visual.
